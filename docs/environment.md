**Рабочая станция разработки (Host / Controller):** `workstation`

## 1. Хост-система разработки (Основной ПК: workstation)

Все данные получены воспроизводимыми системными вызовами на машине `workstation`.

### 1.1. Операционная система и ядро
- **ОС:** Arch Linux (rolling release)
- **Версия ядра:** Linux `7.2.7-arch1-1` (`#1 SMP PREEMPT_DYNAMIC Mon, 21 Sep 2026 18:51:14 +0000 x86_64 GNU/Linux`)
- **Архитектура:** `x86_64` (Little Endian, 48 bits physical, 48 bits virtual)
- **Имя хоста:** `workstation`

### 1.2. Процессор и память
- **Модель CPU:** AMD Ryzen 5 5600X 6-Core Processor (Family 25, Model 33, Stepping 0)
- **Ядра/Потоки:** 6 ядер / 12 потоков, частота до 4654 MHz
- **Виртуализация:** AMD-V (аппаратная поддержка включена)
- **Оперативная память (RAM):**
  - Общий объем: `15 GiB`
  - Занято: `6.4 GiB`
  - Свободно/Доступно: `6.2 GiB` свободно / `9.1 GiB` доступно
  - Swap: `4.0 GiB` (0B занято)

### 1.3. Дисковое пространство
- **Корневой раздел (`/dev/nvme0n1p2`):** Общий размер `228 GiB`, занято `196 GiB`, свободно `21 GiB` (91% utilization).
- **Дополнительный раздел (`/dev/sda1`):** Смонтирован в `/mnt/sda`, объем `110 GiB`, свободно `102 GiB` (рекомендуется использовать для тяжелых деревьев сборки Linux/Mesa при необходимости).

### 1.4. Инструменты сборки и компиляторы
- **GCC:** `16.2.1 20260810` (Target: x86_64-pc-linux-gnu)
- **Clang / LLVM:** `clang version 22.1.8` (Target: x86_64-pc-linux-gnu)
- **CMake:** `4.4.3`
- **Meson:** `1.12.1`
- **GNU Make:** `4.4.1`
- **Rustc / Cargo:** `1.98.1` (channel stable)
- **Git:** `2.55.0`
- **Python:** `Python 3.13+`
- **Графический стек хоста:**
  - `mesa 1:26.2.3-1`
  - `vulkan-icd-loader 1.4.357.0-1`
  - `vulkan-headers 1:1.4.357.0-1`
  - `linux-firmware-amdgpu 20260916-1`
  - `libdrm` (`amdgpu_drm.h`, `amdgpu.h` установлены в `/usr/include/libdrm/`)

### 1.5. GPU на основном ПК (workstation)
> [!IMPORTANT]
> **Не путать с целевым GPU!**
- **PCI ID:** `08:00.0 VGA compatible controller [0300]: Advanced Micro Devices, Inc. [AMD/ATI] Navi 10 [Radeon RX 5600 OEM/5600 XT / 5700/5700 XT] [1002:731f] (rev c1)`
- **Архитектура:** **RDNA 1** (поколение GFX10 / GFX1010).
- **Драйвер:** Встроенный драйвер ядра Linux `amdgpu`.
- Данный GPU **не является** ни RDNA 3, ни RDNA 4. Он обеспечивает графический вывод локальной рабочей станции.

### 1.6. Привилегии пользователя
- Текущий пользователь: non-root (`uid=1000, gid=1000`).
- Вызов `sudo -n -l` возвращает: `sudo: a password is required`.
- **Вывод:** Агент работает в режиме стандартного пользователя без привилегий суперпользователя (passwordless sudo отсутствует). Любые системные операции (монтирование, перезагрузка ядра, установка модулей в корень) требуют явного подтверждения или ручного ввода пароля пользователем.

## 2. Исследование целевого тестового оборудования (Ноутбук)

### 2.1. Верифицированный аппаратный паспорт ноутбука
- **Модель ноутбука:** **Firebat Computer ZhongYan U6C**
- **Имя хоста:** `DESKTOP-UC8P7GQ` (IP в локальной сети: `192.168.1.100`)
- **Версия BIOS:** `American Megatrends 1.07 (ALASKA - 1072009 - 5001D)`
- **Процессор (CPU):** **AMD Ryzen 7 H 255 w/ Radeon 780M Graphics** (архитектура Zen 4, семейство Hawk Point / Phoenix).
- **Графический процессор (GPU):** **AMD Radeon 780M Graphics**
  - **Vendor ID:** `0x1002` (AMD)
  - **Device ID:** `0x1900` (`HawkPoint1` / `Phoenix1`)
  - **Subsystem ID:** `0x80012014`
  - **Revision:** `0xBA`
  - **PNPDeviceID:** `PCI\VEN_1002&DEV_1900&SUBSYS_80012014&REV_BA\4&5B043E7&0&0041`
  - **Архитектура:** **AMD RDNA 3 (iGPU / APU)**
  - **Поколение GFX:** `gfx1103` (GFX11)
  - **Контроллер дисплея (DCN):** `DCN 3.1.4`
  - **Панель экрана (eDP):** 16" 16:10 (34 см $\times$ 22 см)
  - **Разрешение и развертка:** **`2560x1600` при `120 Hz`** (WQXGA)
  - **Выделенная видеопамять (UMA VRAM):** `4 GiB` (`4293918720` байт, выделено прошивкой/VBIOS из системного ОЗУ).
  - **Процессор безопасности (PSP):** `PSP v13.0` (версии `psp_13_0_4` / `psp_13_0_11`)
  - **Контроллер питания (SMU):** `SMU v13.0` (версии `smu_13_0_4` / `smu_13_0_11`)
  - **DMA движок (SDMA):** `SDMA v6.0` (версии `sdma_6_0_4`)

### 2.2. Статус доступа к ноутбуку
- **SSH доступ:** Настроен и проверен с `workstation` (`ssh дрипсайд@192.168.1.100` по ключу `id_ed25519`).
- **Текущая ОС:** Windows 11 с активной службой OpenSSH Server.
- **Статус тестового накопителя:** На основном ПК выполняется фоновая запись загрузочной флешки с **Ubuntu 24.04 LTS Desktop** на `/dev/sdc` (14.6 ГБ).

## 3. Сводка доступности для тестирования

| Компонент | Доступность на Host (workstation) | Статус |
|---|---|---|
| Сборка исходников C/C++ / Rust / Make / CMake / Meson | Полная | Готово к работе |
| Юнит-тестирование независимой логики (pure headers, CLI, симуляторы) | Полная (Clang + ASan/UBSan) | Проверено (`test_xlat12`, `native_rebar_test`) |
| Тестирование на GPU хоста (RX 5700 XT) | Только RDNA 1 (не релевантно для RDNA 3) | Не использовать для RDNA 3 |
| Реальное аппаратное тестирование RDNA 3 | Отсутствует на host | Требуется подключение целевого ноутбука |
